# 焼肉 福朗 — 公式サイト（トップページ）

徳島県板野郡北島町の焼肉店「焼肉 福朗」の1ページ完結型サイトです。
ビルドツール不要の**静的サイト**（HTML / CSS / JS のみ）で、サーバーに丸ごとアップロードすれば動きます。

```
焼肉福朗/
├─ index.html              … トップページ（全セクション）
├─ assets/
│  ├─ css/style.css        … デザイントークン + 全スタイル
│  ├─ js/main.js           … ナビ・スクロール演出・フォーム
│  └─ images/              … 写真 22点（.jpg + .webp）+ favicon.svg
├─ CREDITS.md              … 画像クレジットとライセンス
├─ README.md               … このファイル
└─ 資料/                    … 元の要件メモ・パンフレット（リポジトリ非同梱／ローカル管理）
```

## 1. デザインの変更方法（CSS変数）

デザインの調整は **`assets/css/style.css` の冒頭 2ブロックだけ**で完結します。
コンポーネント側は変数を参照しているだけなので、個別のCSSを触る必要はありません。

### 1-1. テーマをまるごと切り替える

`index.html` の `<html>` タグの `data-theme` を書き換えるだけで、全体の配色が変わります。

```html
<html lang="ja" data-theme="sumi">     <!-- 既定：漆黒 × 淡金（参考サイト準拠） -->
<html lang="ja" data-theme="kinari">   <!-- 明るい和モダン：生成り × 墨 -->
<html lang="ja" data-theme="ebicha">   <!-- 艶やか：海老茶 × 金 -->
```

3テーマとも実装・表示確認済みです。

### 1-2. 新しいテーマを追加する

`style.css` の「2. THEME PRESETS」にあるブロックをコピーし、名前と色だけ変えてください。

```css
[data-theme="あなたのテーマ名"] {
  color-scheme: dark;          /* または light */
  --c-bg:     #000000;         /* 最下層の背景 */
  --c-bg-2:   #000000;         /* 1段持ち上げた面 */
  --c-bg-3:   #0a0a0a;         /* さらに一段上の面 */
  --c-ink:    #ffffff;         /* 主要テキスト */
  --c-ink-2:  rgb(255 255 255 / .74);  /* 副テキスト */
  --c-ink-3:  #8d8d8d;         /* 補助・キャプション */
  --c-accent: #a8332a;         /* 予約ボタンの朱 */
  --c-accent-2: #cebb93;       /* 罫線・欧文ラベルの淡金 */
  --hero-img-brightness: .62;  /* ヒーロー写真の暗さ */
  /* … 既存ブロックの残りの変数もコピーしてください … */
}
```

### 2-2. お問い合わせフォームの送信先設定

現状はバリデーションのみ動作し、送信すると「送信先が未設定です」と表示されます。
`index.html` 内のこの行に送信先URLを入れると、そのまま POST 送信されるようになります。

```html
<form class="form" id="contactForm" data-endpoint="" novalidate>
                                    ^^^^^^^^^^^^^^^^ ここにURL
```

- **Formspree を使う場合** … `data-endpoint="https://formspree.io/f/xxxxxxxx"`
  （`_gotcha` という名前のスパム対策フィールドを既に設置済みなので、Formspree 側で自動的に効きます）
- **自社サーバーの PHP 等を使う場合** … `multipart/form-data` の POST を受け取り、
  成功時に HTTP 200、失敗時に 4xx/5xx を返してください。

送信中・成功・失敗のメッセージ表示は `assets/js/main.js` が自動で行います。

## 4. 実装メモ

### デザイン方針（参考サイト準拠）

[otowa-net.com](https://otowa-net.com/) を実際に解析し、以下の設計言語に合わせています。

| 項目 | 参考サイト | 本サイト |
| --- | --- | --- |
| 配色 | 漆黒 #000 × 白、差し色 #cebb93 | 同じ（差し色 #cebb93、予約導線のみ朱 #a8332a） |
| 見出し書体 | 筑紫Aオールド明朝（有償） | Shippori Mincho（無償の近似明朝） |
| 欧文 | EB Garamond | 同じ |
| 本文 | 游ゴシック 13px / 行間 2.0〜2.4 / 字間 0.12em | 同じ |
| 見出しサイズ | 22〜31px・ウェイト 300 と小さく軽い | 同じ |
| ナビ | PC でもハンバーガーのみ・全画面メニュー | 同じ |
| 縦組み | ヒーローと左右レール、メニューのみ | 同じ（セクション見出しは横組み） |
| 構造 | カード・枠線・角丸を使わず、細い罫線と余白だけ | 同じ（角丸は全て 0） |
| 写真 | 非対称に散らし、間の余白を大きく取る | 想い・こだわりは非対称配置（空間は下記の別参照） |
| ファーストビュー | 写真を固定し、次セクションが上を流れる | 同じ（`--veil-end` で暗転位置を調整可） |
| 影 | 使わない | 使わない |

予約導線（Reservation）セクションのみ、視認性を優先して塗りボタンを残しています。

### こだわりセクション

[otowa-net.com](https://otowa-net.com/) の section03 に倣った構成です。

**段違いの横並び** … 写真と本文を左右に置き、本文だけを一段下げて重心をずらします。
2つの行（黒毛和牛／阿波華牛）は左右を互い違いにしています。

```css
.section--kodawari .media-row { --media-stagger: clamp(2rem, 6vw, 6.5rem); }
```

本文に `padding-block: var(--media-stagger) calc(var(--media-stagger) * .45)` を与えているため、
行の高さは「本文＋上下の余白」で決まり、写真はその行いっぱいに伸びます。
結果として**写真は必ず本文より高く**なります（実測で本文は写真より125px低い）。
900px 以下では1カラムに積み替わり、段差と寄せは解除されます。

**背景の煙** … 参考サイトと同じ考え方で、大きな煙を端から半分はみ出させ、
低い不透明度で重ねています。**右上・左下・右下の3か所**に配置しています。

```html
<div class="smoke" aria-hidden="true">
  <span class="smoke__puff smoke__puff--tr"></span>  <!-- 右上 -->
  <span class="smoke__puff smoke__puff--bl"></span>  <!-- 左下 -->
  <span class="smoke__puff smoke__puff--br"></span>  <!-- 右下 -->
</div>
```

- 素材は「黒地に白い煙」の写真**1枚だけ**（jpg 49KB / webp 19KB）。
  `mix-blend-mode: screen` で黒を透過させ、
  `transform: scaleX(-1)` `rotate()` で反転・回転して3か所に使い回しています
- 濃さは参考サイトと同じ約0.4。`--smoke-blur` は2pxのみです
  （大きくすると煙の形がぼやけて「霞」に見えてしまいます）
- 右下は少し小さく・薄くして奥行きを出しています
- 煙の上に乗る本文のコントラストを実測し、**最低 5.83:1**（AA基準 4.5:1 以上）を確認済みです
- 増やしたい場合は `.smoke__puff` を追加し、位置・回転・`--smoke-size` を指定してください
- 明るいテーマ（kinari）では黒地の素材が使えないため `--smoke-opacity: 0` で非表示。
  使う場合は「白地に黒い煙」の素材を用意し `--smoke-blend: multiply` に変更してください
- 他のセクションに使いたい場合は、そのセクションに `overflow: hidden` と
  `> .container { position: relative; z-index: 1 }` を与え、上記のマークアップを置くだけです

### お問い合わせフォーム

入力欄の位置が分かりにくかったため、**薄い面と枠線**で視認性を上げています。

```css
--panel-bg:       color-mix(in srgb, var(--c-ink) 3%, transparent);  /* フォーム全体の面 */
--field-bg:       color-mix(in srgb, var(--c-ink) 5%, transparent);  /* 入力欄の面 */
--field-bg-focus: color-mix(in srgb, var(--c-ink) 9%, transparent);  /* 入力中の面 */
```

- 文字色（`--c-ink`）を地色にごく薄く混ぜて面を作っているため、
  **暗いテーマでは「薄い白」、明るいテーマでは「薄い墨」**になり、
  どのテーマでも枠が見えます
- 入力欄は「下線のみ」から「薄い面＋全周の枠線」に変更しました
- フォーム全体も薄い面と枠線のパネルで囲んでいます
- もっとはっきりさせたい／もっと控えめにしたい場合は、上の3つの % を変えるだけです

### 余白のリズム

セクション間の余白は **`--sec-gap` 1つ**で決まります。
各セクションはその半分を上下に持つため、隣り合うと合計が必ず `--sec-gap` になり、
どのセクション間も自動的に同じ間隔になります。

```css
--sec-gap: clamp(7rem, 16vw, 16rem);   /* セクション間（合計） */
--sec-py:  calc(var(--sec-gap) / 2);   /* 各セクションの上下 */
```

余白は3段階の階層になっています（1440px時）。

| | 変数 | 1440px | 834px | 390px |
| --- | --- | --- | --- | --- |
| 見出し〜本文 | `--head-gap` | 86px | 50px | 44px |
| ブロック間 | `--block-gap` | 130px | 75px | 64px |
| セクション間 | `--sec-gap` | 230px | 134px | 112px |

実測で全セクション間の余白が一致することを確認済みです（3幅すべて）。

例外は2か所だけで、いずれも意図的なものです。

- **ヒーロー → 想い** … 暗転演出の助走 `--veil-lead` を足しているため広い
- **空間 → 店舗情報** … 空間は全幅スライドショーで終わるため下端を密着させ、
  その分を次セクションの `padding-top` で持たせている（見た目の間隔は他と同じ）

### ファーストビューの動画

肉のアップに炎が立ちのぼる9秒の動画（音声なし・ループ）を背景に敷いています。

| 画面幅 | 読み込むファイル | サイズ |
| --- | --- | --- |
| 900px 以上 | `hero-1280.mp4`（1280×720） | 3.10MB |
| 900px 未満 | `hero-640.mp4`（640×360） | 1.31MB |

モバイル用は macOS の `avconvert`（`PresetAppleM4ViPod`）で 1280 版から作成しています。
Pexels が「640×360」として配信しているファイルは実体が 426×240 と粗く、
スマホの全画面背景では 3.5 倍に拡大されてしまうため使っていません。

- `<video>` の `<source media>` はブラウザに無視されるため、**JS で画面幅を見て
  `src` を設定**しています
- 次の場合は**動画を読み込まず**、ポスター画像のまま表示します
  （mp4 のリクエスト自体が発生しません）
  - 「動きを減らす」設定（`prefers-reduced-motion: reduce`）
  - データセーバー有効（`navigator.connection.saveData`）
  - 回線が 2G / slow-2G
- 画面外では再生を止めます
- **ポスター画像はこの動画の1フレーム**を書き出したものなので、
  読み込み前後で絵が飛びません。JS が無効でもポスターが出るため絵は消えません

### ファーストビューの固定と暗転

参考サイトと同じ「写真が固定されたまま次のセクションが流れ、徐々に暗転する」演出です。

- **固定されるのはヒーローの写真だけ**（`.hero__media` を `position: fixed`）。
  見出し「圧倒的、昭和スタイル」や左右のレールは通常どおりスクロールして消えます。
- 暗転は「想い」セクションの背景グラデーションで行っています。
  停止位置は `--veil-end` で、**セクション高さに対する割合（既定 76%）** で指定。
  02「このタレは本物だ。」のブロックはセクションの 51.5%〜70.5% を占めるため、
  その直後で真っ黒になります。文章量が増減しても割合指定なので比率は保たれます。
- **境目を見せない工夫** … セクション上端で少しでも色が付いていると、
  その境界が横一本の線として動いて見えてしまいます。そのため
  グラデーションは完全な `transparent` から始め、最初の数%はほぼ透明のまま
  （0 → 1 → 3 → 7%）というS字カーブ（全16ストップ）で立ち上げています。
  実測でも境目付近の輝度差は ±1 未満で、写真自体の階調変化（±4〜15）より小さく、

- そのぶん上端は幕が薄いため、`--veil-lead`（既定 42vh）で助走をとってから
  見出しを出し、写真の上でも文字が読める濃さ（約40%）になるようにしています。

### お問い合わせフォーム

入力欄の位置が分かりにくかったため、**薄い面と枠線**で視認性を上げています。

```css
--panel-bg:       color-mix(in srgb, var(--c-ink) 3%, transparent);  /* フォーム全体の面 */
--field-bg:       color-mix(in srgb, var(--c-ink) 5%, transparent);  /* 入力欄の面 */
--field-bg-focus: color-mix(in srgb, var(--c-ink) 9%, transparent);  /* 入力中の面 */
```

- 文字色（`--c-ink`）を地色にごく薄く混ぜて面を作っているため、
  **暗いテーマでは「薄い白」、明るいテーマでは「薄い墨」**になり、
  どのテーマでも枠が見えます
- 入力欄は「下線のみ」から「薄い面＋全周の枠線」に変更しました
- フォーム全体も薄い面と枠線のパネルで囲んでいます
- もっとはっきりさせたい／もっと控えめにしたい場合は、上の3つの % を変えるだけです

### 余白のリズム

セクション間の余白は **`--sec-gap` 1つ**で決まります。
各セクションはその半分を上下に持つため、隣り合うと合計が必ず `--sec-gap` になり、
どのセクション間も自動的に同じ間隔になります。

```css
--sec-gap: clamp(7rem, 16vw, 16rem);   /* セクション間（合計） */
--sec-py:  calc(var(--sec-gap) / 2);   /* 各セクションの上下 */
```

余白は3段階の階層になっています（1440px時）。

| | 変数 | 1440px | 834px | 390px |
| --- | --- | --- | --- | --- |
| 見出し〜本文 | `--head-gap` | 86px | 50px | 44px |
| ブロック間 | `--block-gap` | 130px | 75px | 64px |
| セクション間 | `--sec-gap` | 230px | 134px | 112px |

実測で全セクション間の余白が一致することを確認済みです（3幅すべて）。

例外は2か所だけで、いずれも意図的なものです。

- **ヒーロー → 想い** … 暗転演出の助走 `--veil-lead` を足しているため広い
- **空間 → 店舗情報** … 空間は全幅スライドショーで終わるため下端を密着させ、
  その分を次セクションの `padding-top` で持たせている（見た目の間隔は他と同じ）

- 画面外・タブ非表示のあいだは自動再生を止めます
- 参考サイトには操作UIがありませんが、キーボード操作と
  「動きを減らす」設定の利用者のために、細い線のインジケーターを添えています
  （`prefers-reduced-motion` では自動再生せず、線をクリックして切替）
- 写真を差し替える／枚数を変える場合は `index.html` の
  `.slideshow__slide` と `.slideshow__dot` を同数で増減してください

### セクション見出し

**こだわりセクションの見出しを基準に、全セクションで統一**しています。

```html
<header class="sec-head">
  <p class="sec-head__en">Our Commitment</p>  <!-- 欧文ラベル：EB Garamond 斜体 12px 淡金 -->
  <h2 class="sec-head__ja">こだわり</h2>       <!-- 和文見出し：明朝 31px w300 + 下罫線 -->
  <p class="sec-head__lead">…</p>             <!-- 補足文（任意） -->
</header>
```

揃え方は**左揃え**です。親が `text-align: center` でも見出しは必ず左揃えになるよう、
`.sec-head` と `.sec-head__ja` の両方に `text-align: left` を指定しています。

修飾子は2つだけです。

| 修飾子 | 用途 |
| --- | --- |
| （なし） | 想い／こだわり／空間／店舗情報。**下線も補足文もなし** |
| `sec-head--rule` | ご予約／お問い合わせ。**下線と補足文あり** |
| `sec-head--sub` | セクション内の中見出し（旨さの秘訣）。和文が31px→26pxになる |
| `sec-head--on-media` | 写真の上に置く見出し（ご予約）。文字と罫線が白系になる |

下線は既定では出ません。出したいセクションに `sec-head--rule` を付けてください。
7か所すべてで欧文12px斜体・和文31px（中見出しのみ26px）・ウェイト300・
字間5.58px・左揃えが一致していることを実測で確認済みです。

ご予約セクションは見出しを左揃えにしたため、リード文とボタンも左寄せに揃えています。
以前の中央寄せに戻したい場合は `.reserve` の `text-align` と
`.reserve__actions` の `justify-content` を変えてください。

### ホバー演出

**リンク・ボタン・フォーム入力欄以外にはホバー演出を付けていません。**
写真・カード・見出しなどは静止したままです。
空間セクションのキャプションも、ホバーではなく常時表示にしています。
